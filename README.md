A program that writes one line to `/output/entry.txt` (105 characters, inside the 180-character gate; 19 words, inside the 25-word cap): a one-star review of Monday written as if Monday were a restaurant — seated beside the unread emails, served cold coffee, billed for the whole week. A real diner's complaint (table, dish, bill) that only works for Monday.

## Run it

```sh
python3 main.py
```
